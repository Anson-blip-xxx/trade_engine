添加 API 凭据

API Key 和 Secret 使用 AES-256-GCM 加密入库；提交后不回显。请勿在别名中填写密钥。环境必须与创建 Key 的平台一致，暂不自动联网验证。

修改所选账户 API Key / Secret

只更新同一币安账户、同一环境的凭据。换到另一个币安账户请使用“添加 API 凭据”，不要覆盖此处。旧密钥不回显，两个字段必须一起填写。修改后需要重新验证，不会自动启用或切换交易。

执行切换申请与进度

申请只登记所选环境的目标账户，不等于交易已经切换。执行控制器尚未接入时，申请会被明确阻断。测试与生产分别记录，不能互相替代。
