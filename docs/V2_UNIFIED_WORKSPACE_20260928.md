# 三页统一工作空间交付

2026-09-28，UTC+8。范围：交易看板 `/`、账户管理 `/accounts`、策略工作台 `/accounts/strategy`。

## 统一方式

- 三页真正引用同一份 `web/v2_workspace/app.css` 和 `app.js`，不是复制三套侧栏再分别维护。
  公共组件统一导航顺序、当前页标识、字体、底色、按钮、卡片、页签、间距及响应式断点。
  页面自己的 CSS 只保留业务组件；策略页原有重复基础规则已移除。
- 桌面固定左侧导航，手机固定顶部三页导航；支持键盘与屏幕阅读器当前页标识。
  三页都可直接访问，深链接、刷新、浏览器前进后退不要求 SPA 或新增前端框架。
- 账户/环境/策略统计天数通过受约束的 URL 参数随导航传递。账户管理与策略页互相往返
  保留选择；由账户列表再次确认可见性，UUID 不是授权依据。无效/不可见账户会明确提示回退。
  不使用 localStorage、sessionStorage 或本地文件保存业务状态、凭据或查看上下文。
- **首页仍是当前实际执行账户监控**，不是任意账户的交易控制器。
  从其他账户或生产分析返回首页时，明确提醒首页的执行作用域，并保留原分析账户返回入口。
  查看账户绝不自动申请执行切换，生产执行仍关闭。

## 操作整理

- 首页分总览、交易记录、信号监控、链路诊断。首屏显示核心指标、链路异常提示、收益与仓位。
  交易记录每页 20 条，最多使用接口既有 100 条数据；支持筛选/搜索。详情改成原生对话框，
  支持键盘聚焦、Esc 关闭，保留异步详情失效保护。每日不同收益口径折叠说明。
- 账户管理分账户概况、验证与切换、API 凭据。明确区分“添加新账户”和“更新同一账户凭据”。
  当前目标账户、签名只读检查、真实执行状态、切换申请分开呈现；高影响切换保留原二次确认。
  概况提供前往验证、编辑凭据、查看所选账户策略表现的直接入口。
- API 输入继续为 password 类型、发送后清空、不回显；账户资料/凭据草稿在切换和离开时提醒。
  创建或改名请求晚到，不跳回旧账户；旧请求也不能清空已经输入的新草稿。
- 账户金额统一为展示用最多两位小数，无已结算样本显示“—”，不把缺失业绩当作盈利。
  只改变显示格式，不改变数据库数值、公式或精度。说明账户累计统计与策略时间窗口不同。
- 策略页沿用百分比精确换算、70% 上限、预览、版本冲突保护、幂等发布、只读生产等规则。
