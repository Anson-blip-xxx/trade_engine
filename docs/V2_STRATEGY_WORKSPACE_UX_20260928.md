# 策略工作台 UX 改造

日期：2026-09-28，UTC+8。入口：`/accounts/strategy`。

## 范围与使用方式

本轮重做用户当前打开的策略分析/配置页面，不宣称其他账户管理、交易首页已统一改版。
交易策略、定仓公式、账户权限和后端接口保持原样；不是一次交易系统升级发布。

- 桌面侧栏与手机顶部提供交易看板、账户管理入口。账户/环境/统计范围集中在顶部，
  明示此处只切换查看对象，不切换执行账户。执行账户标识仅表示页面载入时读取的路由。
- 五个页签：总览、交易明细、信号诊断、资金设置、变更记录。支持键盘左右键和 Home/End，
  链接可直接使用 `#risk` 等页签锚点。页签之间切换不丢失草稿。
- 总览优先显示已结算净收益、胜率、结算数、持仓时间。正负收益分别着色，
  缺失数据不显示为零；净值观测与策略已结算收益分开。图表可用滑块/键盘查看观测点。
- 交易明细支持币种搜索、来源/盈亏筛选、收益/持仓时间排序、每页 20 条及详情弹窗。
  只筛选接口已经返回的样本，不冒充无限历史检索；技术追溯字段折叠显示。
- 信号常见拒绝原因给出中文解释，保留原始原因可展开查看；回执数不冒充独立信号数。
- 基础资金设置与高级参数分组。显示 5% 而不是要求输入 0.05；文字说明每项用途。
  字符串十进制换算避免二进制浮点噪声，未编辑的高精度值不会重写。
- 总资金池上限一个入口，修改时同时预览 `capital.pool_fraction` 和 `sizing.pool_fraction`。
  历史两值不同会提示，不会在页面加载时自动修正。保留最高 70%、至少预留 30% 的后端约束。
- 修改 → 预览差异/算术例子 → 填写原因 → 二次确认发布；保留版本校验、预览过期、
  幂等 request_id 和响应不明时原请求重试。结果未确认时锁定表单，防止替换重试载荷。
- 切换账户/环境/范围、刷新及离开页面时保护未发布草稿；取消切换会恢复原选择。
  LIVE 只读历史值即使不满足新版编辑约束，也不会被误判为“用户未保存修改”。
- 失败时清除旧账户数据并提供重试；首次账户列表请求失败同样可以直接重试。
- 360、390、768、1440px 布局验收，长历史说明与选择框不撑宽手机页面；表格仅在自己的区域滚动。
