# V2 Testnet 连续运行发布与门禁（2026-09-23）

## 发布边界

- 环境：Binance Demo/Testnet；不得加载 LIVE 凭据。
- 已发布不可变 release：`a6f509c6b556a546c5a606cbec9f2d9591528335`。
- entry、保护单写入、reduce-only 退出三项 Testnet 权限均开启。
- PG、Redis、ClickHouse、统一 daemon、独立 watchdog 均已设置开机启动。
- daemon 使用 `Restart=always`；watchdog 使用 `Restart=always`。依赖服务继续使用各自
  的受控恢复机制，启动顺序由 unit 的 `Requires/After` 和 daemon preflight 约束。

这次发布不授权 LIVE，不修改或复用旧 main 运行目录，不把短期 Testnet 收益解释为
未来盈利保证。

## 自动恢复实测

发布后分别向 daemon 与 watchdog 主进程注入一次 `SIGKILL`：

- daemon 自动获得新 PID，`NRestarts=1`；
- watchdog 自动获得新 PID，`NRestarts=1`；
- 恢复后最新检查点重新达到 `RUNNING / CYCLE_COMPLETE`；
- 最新周期的保护、退出、结算阶段均为 `CLEAR`；
- PG 中 HELD 风险预留为 0。

该测试证明单进程崩溃可自动恢复，不等价于整机断电、磁盘损坏或外部依赖长时间不可用。
整机 reboot 仍保留为切换前演练项。

## 观察窗口

先连续运行 72 小时验证稳定性。如果 72 小时内已结算交易少于 20 笔，则继续运行，直到
同时满足“至少 7 个自然日”和“至少 20 笔已结算交易”，再评估策略质量。这样可避免把
一两笔偶然盈亏当成策略结论。

运行门禁：

1. daemon、watchdog 与三个依赖无未解释的退出循环；心跳不存在持续缺口。
2. 新仓必须有对应保护；不得出现长期裸仓、重复交易所订单或 UNKNOWN 身份盲重试。
3. 每笔开仓均能追到信号、候选、决策版本、风险预留、订单、成交、费用、平仓原因、
   settlement 与 outcome；没有孤立订单或无法归属的资金流水。
4. 每个终态 episode 的风险预留都已释放；未完成结算、迟到流水和 T60 缺口必须显式
   留在待处理状态，不能静默标记成功。
5. PG 是交易事实源，Redis 仅为可重建投影，ClickHouse 仅承载行情/分析归档；不得出现
   本地文件交易状态回退。

策略评估至少输出：交易数、净收益、手续费与资金费、胜率、profit factor、最大回撤、
平均/分位持仓时长、按策略/方向/标的/退出原因拆分的收益，以及开仓后 MFE/MAE。任何
缺失证据、样本不足或单一标的贡献过度集中，都应阻止“数据理想”的结论。

## LIVE 候选条件

满足观察窗口不代表自动切换实盘。只有以下条件同时成立，才可提交 LIVE 切换候选：

- 运行与数据门禁全部通过；
- 样本量达到上述最低要求，净收益、profit factor 和最大回撤符合届时明确批准的限额；
- 完成整机 reboot、备份恢复和 release 回滚演练；
- 使用独立 LIVE 账户绑定、独立凭据、独立数据库命名空间和更小的首发风险上限；
- 用户单独批准 LIVE 凭据、切换时间窗和账户风险参数。

若任一门禁失败，系统继续留在 Testnet；保护、退出和结算可以继续运行，但新开仓应按
既有失败关闭机制暂停，不通过人工补写状态绕过。

## 交易 Telegram 通知

Testnet daemon 已接入独立的持久交易通知投影器。开仓消息仅在交易所成交身份、实际
fills、readiness 和保护单确认后发送；平仓消息仅在仓位归零、费用/资金费核对、settlement
与 outcome 完成后发送。模板包含策略、事件、方向、评分、杠杆/保证金、成交均价和数量、
计划/实际名义价值、计划损失、止损与保护单、毛利、费用、资金调整、净利、收益率、
R 倍数、持仓时间和退出原因。用户可见消息不展示账户、episode、signal、order、event、
保护单 ID 或结算版本等追溯身份；追溯证据只保留在 PG。所有消息时间显式标注 `UTC+8`。

投递使用 PG outbox、租约、退避和消费回执；TG 不可用不会回滚交易或阻塞保护/退出/结算。
Telegram 不提供幂等键，若远端成功而本地回执提交失败，极端情况下可能重复通知；消息中
重试不会触发任何交易操作。时区存储与显示契约见
[V2 时间契约](V2_TIMEZONE_POLICY.md)。
