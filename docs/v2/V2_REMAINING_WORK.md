## 已具备的核心能力

- PG 信号、不可变决策与配置、意图、订单 CAS、成交账本、资金流水及资金费分配。
- UNKNOWN 原身份查询、不重复提交；历史费用估值、精确盈亏、结算版本绑定。
- Redis 可重建投影、ClickHouse 事件去重、outbox 回执及带租约重试。
- 新增 `StrategyScheduler`：PG 持久任务、公平发现、逐条领取、失败退避、
  租约回收与令牌隔离；容量等待继续处理，原决策期限不延长。
- 隔离事务/并发/故障注入、备份恢复、临时 PG 崩溃恢复；新增贯穿测试将
  信号→策略→Binance 协议模拟→丢响应恢复→开平仓账本→资金费→结算→Redis 重建连接验证。

以上是模块能力，不代表下列接线工作完成。

## QA 边界

所有新测试仅使用一次性 PG/Redis、独立 ClickHouse local 和注入交易所响应。
贯穿测试确实经过 `BinanceFutures` 协议解析，但没有真实 API、保护单，
风险检查和结算证据是显式 QA 替身，不能称为生产完整 E2E。
盈利/亏损数值证明的是账务拆解，不是策略因果或未来收益承诺。

当前初始化 SQL 是 greenfield schema，不是已部署数据库的升级脚本。
未来切换前必须验证实际 schema/权限/依赖；当前开发不对运行数据库执行它。
