# S6/S8 真实规则准入与原始止损恢复

实现 `services/v2_directional_admission.py` 和 `services/v2_directional_protection.py`。
这是策略到持久订单及保护计划的接线，不是已上线的自动交易服务，不证明策略盈利。

- 与现有回放共用真实 S6/S8 规则、历史质量、仓位计算、资金费及收益风险比检查。
  仅最终全部通过的候选转换为 OPEN；严格映射 LONG→BUY、SHORT→SELL。
- 默认拒绝构造正式准入器，需要显式 `enable_admission=True`、SANDBOX 绑定运行时、
  相同账户执行器及风险参考端口。拒绝配置时不消耗正式信号回执。
- 正式消费者为 s6/s8，回放仍为 s6-replay/s8-replay，互不占用。配置、上下文、
  计算结果、止损/杠杆计划、期限进入不可变 PG 决策；订单只能 PREPARED，组件不提交。
- PG 调度器提供持久任务、租约、重试和恢复；重启重用原决策，不能重新计算或延长
  过期信号。并发消费同信号只登记一个订单。
- `DirectionalStopRecovery` 通过 order→intent→不可变 evidence 找回最初的止损价，
  校验版本/账户/策略/方向/数量/原始结果，拒绝旧系统订单。开仓期限过期不妨碍保护
  已有仓位，但创建保护仍需新的账户和行情核验。
- 原始计划接入上一节点的开仓冻结、撤余单恢复及受控止损安装。默认禁写；仍不能
  把未确认撤单称为已保护。实际部署未开启此组件或新的交易权限。
